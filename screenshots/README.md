## How to Capture Clean Screenshots on Windows

1. **Using Windows Snipping Tool (Recommended):**
   - Press **`Win + Shift + S`**.
   - Select the **Window Snip** or **Rectangular Snip** mode.
   - Click on your terminal window or VS Code.
   - Paste or save into this `screenshots/` directory.

2. **Capturing the Active Terminal Window:**
   - Click the terminal or VS Code window to focus it.
   - Press **`Alt + PrtScn`** (copies only active window to clipboard).
   - Open Paint or an image editor and press `Ctrl + V`, then save as PNG into `screenshots/`.

## Recording a Video / Screen Recording for LinkedIn / College Submission

If your internship requires a video demonstration or LinkedIn post:
- **Windows Built-in Screen Recorder:** Press **`Win + Alt + R`** (Xbox Game Bar recorder) or use the Windows 11 Snipping Tool screen recorder.
- **OBS Studio:** Free and open source, ideal for recording terminal and VS Code demos.
- **Suggested Demo Flow (2-3 minutes):**
  1. Show folder structure in VS Code.
  2. Run the unit test suite (`python tests/test_tasks.py`).
  3. Execute 2-3 key tasks live in PowerShell (e.g., Password Generator, File Organizer dry-run, Web Scraper).
  4. Showcase Git commit history (`git log --oneline`).
